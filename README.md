# 幼猫健康科普站

面向城市养猫新手的疾病科普静态站点，围绕「预防 — 发现 — 干预 — 救治」组织内容，共 6 个页面。

## 技术
- HTML5 语义化结构 / CSS3（CSS 变量、Grid、Flex、媒体查询、clamp、object-fit）
- 原生 JavaScript：回到顶部、导航高亮、阅读进度条、图片懒加载
- 无框架、无构建，图片全部本地化，断网可访问

## 页面
| 文件 | 内容 |
| --- | --- |
| index.html | 首页：现状、四步路径、疾病速览 |
| diseases.html | 8 类高发疾病与鉴别表 |
| identify.html | 早期识别与家庭初步干预 |
| prevention.html | 疫苗 / 驱虫 / 环境 / 营养 |
| treatment.html | 就诊流程与治疗手段 |
| sources.html | 参考资料与图片来源 |

## 运行
双击 index.html 即可，或用 `python -m http.server` 起本地服务。

> 内容为科普整理，不替代执业兽医诊断。
